# 🗳️ Voting App

A beautiful and interactive voting application built with HTML, CSS, and JavaScript.

## Features

✨ **Interactive Voting** - Cast your vote with a single click
📊 **Real-time Results** - See live vote counts and percentages
💾 **Local Storage** - Votes are saved in your browser
📱 **Responsive Design** - Works great on mobile and desktop
🎨 **Beautiful UI** - Modern gradient design with smooth animations

## How to Use

1. Click on any option to cast your vote
2. Watch the results update in real-time
3. See the vote distribution in the results chart
4. Click "Reset Votes" to clear all votes

## Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling and animations
- **Vanilla JavaScript** - Functionality
- **LocalStorage API** - Data persistence

## Deployment

### Deploy to Vercel (Recommended)

1. Sign up at [Vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Click "Deploy"
4. Your app will be live in seconds! 🚀

### Deploy to GitHub Pages

1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose the `main` branch
4. Your app will be live at `https://error0061983-hub.github.io/voting-app-`

## Local Development

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server -p 3000
```

Then open `http://localhost:8000` in your browser.
